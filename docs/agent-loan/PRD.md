# PRD: 대출문의 에이전트 (대출문의 — 만기/연장/조회 등)

- 담당: 팀원A · 브랜치: `feat-agent-loan`
- 먼저 읽을 문서: `docs/PRD.md`, `docs/ARCHITECTURE.md`(계약 3~6), `docs/ADR.md`

## 목표
대출 만기·연장·조회 문의에 mock 대출 API를 조회해, 전문적인 존댓말 상담 답변을 돌려준다.

## 담당 범위
1. mock 대출 API와 데이터(`C001`~`C003`, 대출 ID `L001`·`L002`는 이자/연체 mock과 공유 — 계약 6)
2. `agent.handle()` — 조회, 대출 선택 되묻기, 프롬프트 구성, 출력 검증
3. `cs-loan` 모델 — 전처리, QLoRA 학습, GGUF 변환, Modelfile

## 사용자 스토리
1. 대출 1건 고객(`C002`)이 "제 대출 만기가 언제예요?"를 보내면 만기일과 남은 원금을 받는다.
2. 대출이 없는 고객(`C001`)은 "조회되는 대출이 없습니다" 안내를 받는다.
3. 고객이 "대출 만기 연장하려면 뭐가 필요해요?"를 물으면 연장 가능 여부와 일반 절차를 안내받는다. 구체적인 서류·조건은 지어내지 않고 상담원 확인을 안내한다.

## 슬롯
| 슬롯 | 예시 값 |
|------|--------|
| `{{loan_label}}` | 신용대출 |
| `{{principal_remaining}}` | 12,000,000원 |
- 금액이 아닌 정보(만기일, 연장 가능 여부, 대출 종류)는 프롬프트에 넣어도 된다. 금액은 슬롯으로만 전달한다.

## 인수 기준 (이 영역 책임)
- PM 고정 질문 10건 중 9건 이상 통과(주제 적합 · 지어내지 않음 · 존댓말 톤)
- 지어낸 사실 0건 — 특히 금리 수치, 실제 상품명, 연장 서류 요건
- `pytest backend/tests/loan` 통과(모델 호출은 목으로 대체)

## 제외
- 대출 신청·승인·실제 연장 처리, 금리 계산, 이자·연체 안내(이자/연체 에이전트 담당)

## 확인 필요
- 연장 절차 안내를 학습 데이터의 일반 안내 수준에서 어디까지 허용할지는 PM 고정 질문으로 판정한다.
