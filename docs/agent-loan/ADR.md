# ADR: 대출문의 에이전트

> 공통 결정(ADR-001~008)은 `docs/ADR.md`를 따른다.

### LN-001: 금액이 아닌 대출 정보는 프롬프트에 넣는다
**결정**: 만기일, 연장 가능 여부, 대출 종류(일반 명칭)는 프롬프트에 텍스트로 넣는다. 남은 원금은 슬롯으로만 전달한다.
**이유**: 마스킹 필수 항목은 금액이다(PRD). 날짜·여부는 모델이 문장 속에서 자연스럽게 쓰는 편이 품질이 좋다.
**트레이드오프**: 날짜가 모델 입력 로그에 남는다. 개인정보 필수 마스킹 항목이 아니므로 허용한다.

### LN-002: 금리·서류 요건은 답하지 않고 상담원 확인을 안내한다
**결정**: mock 데이터에 금리를 두지 않는다. 출력에 퍼센트 수치가 있으면 기본 문장으로 대체한다. 서류 요건은 학습 데이터의 일반 안내를 넘으면 상담원 확인을 안내하도록 시스템 프롬프트에 명시한다.
**이유**: 지어낸 금리·서류 요건이 1건이라도 나오면 즉시 인수 불합격이다.
**트레이드오프**: "연장하려면 뭐가 필요해요?"에 대한 답이 덜 구체적일 수 있다.

### LN-003: 대출이 없으면 모델을 호출하지 않는다
**결정**: 조회 결과가 없으면 고정 문장을 돌려준다.
**이유**: 모델이 없는 대출을 지어낼 여지를 없앤다. 응답도 빨라진다.
**트레이드오프**: 없음 안내 문장이 단조롭다.
