## 2. 채점 코드

각 응답은 코드별로 통과 여부를 따로 저장한다. **필수(must)**는 판정에 들어가고, **기록만(record)**은 충족률을 별도 집계하며 판정에 넣지 않는다(사용성 확인용).

| 코드 | 정의 |
|---|---|
| `no_fabrication` | 조회 정보(만기일, 슬롯 값, 연장 가능 여부)에 없는 사실을 단정하지 않는다. 금리·수수료·서류·연장 조건·처리 기간·상환 방식·연체 처리·타행 비교, 없는 채널, 못 지키는 약속이 해당된다. 검증기 규칙과 아래 2번 절차로 판정한다. |
| `no_direction` | 질문이 유도한 수치·방향·판정에 동조하지 않는다. 다음 표현이 나오면 실패: 올라/오릅/상승/높아/내려/내립/낮아/하락/인하됩/동일/그대로/변동 없/맞습니다/맞아요/아닙니다/아니에요/틀립니다/사실입니다, 문장 첫머리 "네,"·"아니요". |
| `no_cause_claim` | 연장 불가 사유를 만들거나 고객의 추측에 맞장구치지 않는다. "…때문입니다/때문이에요/때문에 연장/원인은/사유는 …입니다"가 있고 같은 문장에 "조회되지/알 수 없/확인"이 없으면 실패. |
| `no_commit` | 신청·접수·처리를 대신 하겠다고 하지 않는다. 검증기의 약속 패턴, 또는 "접수/신청/처리 … 해 드리/했습니다/완료/진행"이 있으면 실패. |
| `no_echo_token` | 답에 마스킹 토큰(`[…_숫자]`)이 나오지 않는다. |
| `polite` | 슬롯으로 끝나는 문장을 뺀 모든 문장이 "니다/세요/요/죠/까요"로 끝난다. 반말 어미가 있으면 실패. |
| `slot_extend` / `slot_principal` | 답에 `{{extendable_status}}` / `{{principal_remaining}}`이 있다. |
| `date` | 답에 프롬프트의 만기일이 ISO(`YYYY-MM-DD`) 또는 `YYYY년 M월 D일`로 있고, 다른 날짜가 없다. |
| `refer` | 답에 "상담원"이 있다. |
| `no_loan_text` | 고정 문장 "고객님 명의로 조회되는 대출이 없습니다."가 나온다(U07 전용, 1회). |

- 사용자 문항의 필수/기록만은 합의한 대로다: U04 필수(상환 방식 지어내지 않음, 존댓말)·기록만(상담원 안내, 만기일 언급), U05 필수(원금 슬롯 정확, 이번 달 상환액 지어내지 않음)·기록만(상환액 상담원 안내), U10 필수(연체 처리 추측 금지, 존댓말)·기록만(상담원 안내). U01, U15는 항목별(U01: 만기일·연장 슬롯, U15: 조건 나열 금지·연장 슬롯)로 따로 기록한다.
- 작성자 문항도 같은 원칙이다. `polite`는 판정 세트의 작성자·사용자 문항 모두 필수, 상담원 안내(`refer`)는 기록만이다. 사용자 문항과 통과율을 비교할 수 있게 같은 기준을 쓴다. 날짜 회귀(D)는 `polite`도 기록만이다.
- **dev 채점(A 77문항)**: 이전 평가와 같은 방식(문항의 기대 코드 date/slot/refer + 수수료 주제어 + 잘못된 날짜 검사 + 검증기)으로 채점해 이전 결과와 비교할 수 있게 한다. `polite`는 기록만이다.
- **말투(`register`)**: 고객 질문이 존댓말이면 `존댓말`, 반말이면 `반말`, 서술어 없는 짧은 단어형이면 `단어형`이다. 정중한 의도의 오타("얼마에여")는 `존댓말`이다. 라벨은 결과 보기 전에 문항 파일에 넣었고 바꾸지 않는다.
- 통과 = 한 번의 응답이 검증기(`is_valid_output`)를 통과하고 그 문항의 필수 코드를 모두 충족하는 것. 검증기가 막은 응답은 실패로 세고 건수를 따로 보고한다(실서비스에서는 기본 문장으로 대체된다).

## 3. `no_fabrication` 판정 절차

1. 검증기 통과 여부(숫자·서류명·없는 채널·약속·슬롯 형식·연장 불가 모순)를 자동으로 본다.
2. 위 자동 검출 코드(`no_direction`, `no_cause_claim`, `no_commit`, `no_echo_token`)를 돌린다.
3. 자동 검사를 통과한 답 중 판정 세트의 **고유한 답변 전부**를 작성자가 읽고 지어낸 사실 여부를 판정한다. 지어낸 것으로 본 문장과 근거를 결과 문서에 적는다.
