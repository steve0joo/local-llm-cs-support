## 1. 목적

이전 실험(v01·v02)에서 AI Hub 정답만으로 학습하면 모델이 **이자 정보와 슬롯을 무시하고 금리를 지어냈다**(슬롯 사용 0%, 규칙 준수 21%). v03의 목적은 두 가지다.

1. 우리 서비스 규칙(조회값만 사용, 금액은 슬롯, 모르면 상담원 안내)을 가르치는 **합성 샘플**을 넣으면 파인튜닝 전 모델(Base)보다 나아지는지 확인한다.
2. 학습 강도를 낮춰(1e-4, 2 epoch) Base의 좋은 능력을 덮어쓰지 않는지 확인한다.

## 4. 결과

### 4-1. 학습은 안정적이었나? → 예

```
train loss  2.04 ─┐
                  1.38 ─ 1.05 ─ 0.94 ─ 0.71 ─ 0.63 │ 0.65 ─ 0.55 ─ 0.54 ─ 0.58 ─ 0.53 ─ 0.48
                  (epoch 1)                         │ (epoch 2)
eval loss                                   1.04    │                                   1.00
```

| 지표 | 값 | 판단 |
|---|---|---|
| train loss | 2.04 → 0.48 | 정상 감소 |
| eval loss | 1.04 → 1.00 | 오르지 않음 → 과적합 징후 없음 |
| grad_norm | 최대 2.9, NaN 없음 | 안정 |

train loss(0.48)가 eval loss(1.00)보다 많이 낮은 건 합성 문장이 반복되기 때문으로 보인다. epoch를 늘리면 문장을 외울 수 있어 2 epoch를 유지한다.

## 5. 남은 문제

자동 평가에서 틀린 6문항과, 답변을 직접 읽어 찾은 문제를 합쳤다.

| # | 문제 | 예시 (v03 답 요지) | 심각도 | 자동 검사로 잡혔나 |
|---|---|---|---|---|
| 1 | **모르는 것을 단정** | (납부일 변경 질문) "옮기실 수는 **없습니다**" | 🔴 지어낸 사실 | ✅ (기대 조건) |
| 2 | **지킬 수 없는 약속** | (가족 명의 대출) "본인확인 절차를 거쳐 **확인해 드리겠습니다**" | 🔴 | ✅ |
| 3 | **조회값에 없는 원인 단정 + 문장 반복** | (자동이체인데 왜 연체) "자동이체가 정상적으로 처리되지 않았기 **때문입니다**. … (같은 문장 2번)" | 🟠 | ❌ |
| 4 | **채널을 가정한 안내** | (가상계좌) "계좌 번호는 고객님의 **앱이나 고객센터**에서 확인하실 수 있습니다" | 🟡 | ❌ |
| 5 | 평가 기준이 좋은 답도 틀렸다고 봄 | 감면 요청 2건·연체 일수·상환 방식 표현 | – | (기준 문제) |

- Base도 같은 질문에서 "연체 기록 삭제는 **가능합니다**", "부모님 명의 대출은 **확인이 가능합니다**"처럼 지어냈다. Base보다 나아졌지만 **자동 지표만으로는 부족하다.**
- 3·4번은 자동 검사가 놓쳤다. 사람 평가가 꼭 필요한 이유이고, 검사 항목에 추가해야 한다.
