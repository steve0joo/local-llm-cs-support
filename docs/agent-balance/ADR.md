# ADR: 잔액조회 에이전트

> 공통 결정(ADR-001~008)은 `docs/ADR.md`를 따른다.

### BAL-001: 조회 대상·의도 판단은 Python 코드, 문장 생성만 모델
**결정**: 계좌 매칭, 잔액/거래내역 구분, 슬롯 값 생성은 코드로 한다. 모델은 슬롯 이름으로 상담 문장만 만든다.
**이유**: 원본 계좌번호와 금액이 모델에 닿지 않는다. 결과가 결정적이라 테스트하기 쉽다.
**트레이드오프**: 키워드 규칙이 놓치는 표현이 있을 수 있다. 자체 점검 셋에 넣어 보완한다.

### BAL-002: 출력 검증 실패 시 기본 문장으로 대체
**결정**: 모델 출력에 필수 슬롯이 없거나 금액 형태의 숫자가 있으면 고정 템플릿 문장을 쓴다.
**이유**: 잔액 화면 인수 기준(모델은 `{{balance}}` 생성, 화면에 실제 금액)과 "지어낸 사실 0건"을 모델 품질과 상관없이 보장한다.
**트레이드오프**: 대체 문장은 단조롭다. 대체 빈도를 로그로 보고 학습 데이터를 보강한다.

### BAL-003: 계좌가 여러 개면 선택지로 되묻는다
**결정**: 대상 계좌를 정하지 못하면 계좌 라벨 버튼을 보여준다(`choice: "balance"`).
**이유**: 타이핑 없이 한 번 눌러 끝낸다(적은 프로세스). PRD의 "3턴 이상 허용" 범위 안이다.
**트레이드오프**: 턴이 하나 늘어난다.
